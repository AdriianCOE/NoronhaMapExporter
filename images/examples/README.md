# Product examples

These are compact JPEG viewport samples from the validated Noronha development terrain. They are documentation only, not reusable terrain data, source captures, or full-world masters.

| File | Demonstrates |
| --- | --- |
| `raw-map.jpg` | native MapWidget reference |
| `engine-clean.jpg` | the public property-based clean/topographic direction |
| `satellite-engine.jpg` | terrain-provided satellite imagery rendered by the engine |

The full RAW and engine-clean reference masters remain ignored local artifacts. These examples are intentionally small so repository history does not contain production map output.
