# Product examples

These are compact JPEG documentation images from a custom development terrain.
They are not reusable terrain data or source captures.

| File | Demonstrates |
| --- | --- |
| `noronha-master.jpg` | current Fernando de Noronha Tourist master with hillshade |
| `raw-map.jpg` | native MapWidget reference |
| `engine-clean.jpg` | current clean MapWidget master without Tourist effects |

The 9600 px source master remains an ignored local artifact. These examples stay
small so repository history does not contain production map output.
