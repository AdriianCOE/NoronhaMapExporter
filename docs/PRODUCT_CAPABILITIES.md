# Product capabilities

## One local configuration

`config.json` is the single entry point for paths, world identity, capture settings, requested scales, cartography, and optional satellite input. It is not committed. Start from `config.example.json`.

`run-2d.ps1` validates this file before it builds anything. It then creates a temporary property-based `RscMapControl` override, builds the addon through RaG DayZ Tools, starts the lossless capture helper, launches DayZDiag, and stitches each enabled export after the user confirms it completed.

`run-satmap.ps1` is intentionally narrower. In `source` mode it validates a real source image and writes an unchanged RGB lossless PNG with a manifest. It does not claim registration or alignment that it cannot prove.

## Public cartography properties

| Property | Effect |
| --- | --- |
| `grid`, `gridNumbers` | coordinate lines and their labels |
| `locationLabels`, `locationIcons` | native location names and `NameIcon` points |
| `vegetation` | forest fill/border visibility, colour, opacity |
| `contours` | normal/main contour visibility, colour, opacity |
| `roads`, `tracks`, `buildings` | their respective map-rendered layer visibility |
| `colors` | background, outside map, and sea colours |
| `satmap.mode` | `engine` terrain-imagery composite or separate `source` export |
| `hillshade` | optional ASC-derived tourist output; requires a compatible source heightmap |

The default example keeps vegetation and contours visible. Clean means removing interface clutter, not flattening terrain information.

## Known engine limit

Object icons such as certain hospitals, fuel stations, or towers may remain. Some roads, building footprints, and vegetation symbols can also remain in an engine-satellite composite. They resolve through DayZ's runtime `MapDefaults`; reopening or subclassing it from an addon caused config conflicts or had no observable runtime effect. The exporter intentionally does not attempt unsafe overrides. If a caller adds `mapObjectIcons: false`, generation reports that it was not applied.

## Outputs

The 2D manifest records the exact session source, SHA-256 hash, scale, and metres-per-pixel for each master. The stitcher reports its deterministic `bounds-geometric-midpoint-overlap-crop` method. Satellite source output has its own manifest with source filename, input format, dimensions, declared world size, and SHA-256.

No full-world master is part of Git. The Noronha raw and engine-clean masters are immutable local references and are not regenerated by product commands.

Hillshade is post-processing only. It uses the configured ASC, validates its physical extent against `world.size`, masks water with explicit `seaLevel`, and writes `tourist/<name>_hillshade.png` without replacing `2d/<name>.png`.
